# madspild-webapp
Madspild Webapp
Projektbeskrivelse
Dette projekt udvikles som en del af kandidatuddannelsen i Digitalisering og Applikationsudvikling (DAD) ved Aalborg Universitet.

Formålet er at udvikle en webbaseret løsning, der kan bidrage til at reducere madspild.
